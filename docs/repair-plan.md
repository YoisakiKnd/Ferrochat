## 前后端交互复核（2026-10-01）

### 已修复

- **文件夹操作接口缺失。** 补齐展开状态、父文件夹移动和文件夹聊天导出路由；返回实际关联聊天，避免聊天移入文件夹后不可见或在普通列表重复出现。
- **文件夹删除后内容无法访问。** 在事务中将聊天与直接子文件夹移回侧栏；同步修正删除确认文案。父文件夹移动拒绝跨账户引用与循环嵌套。
- **侧栏操作事件异常。** 修复文件夹菜单点击被拦截、嵌套按钮和销毁时重复注册拖放监听；防止连续点击重复创建文件夹，移除无效的临时文件夹状态。
- **聊天断线无反馈。** 连接不可用时保留发送草稿；回复过程中断线时结束等待状态并提示重试，取消已知任务及稍后返回的任务。
- **停止回复的时序问题。** 尚未收到任务编号时也能立即停止界面等待，编号返回后取消任务；多个模型仍在回复时保留停止入口所需的任务列表。
- **附件上传失败静默。** 网络异常与代理返回的非 JSON 错误均显示原因，失败附件从输入区移除。
- **密码修改失败无法方便重试。** 失败或确认密码不匹配时保留输入，提交期间阻止重复提交，新密码增加最小长度校验。
- **桌面分支引用缺失。** 补齐布局中的 `appData` 导入，避免执行相应分支时产生运行时异常。

## 分享、语音与导入复核（2026-10-01）

### 已修复

- **分享链接错误与匿名访问失败。** 使用 `share_id` 生成公开链接；匿名或失效登录状态下可访问分享页；失效链接与网络错误显示原因并提供重试。
- **分享内容随私有聊天变化。** 新增 `006_share_snapshot.sql`，在事务内升级现有链接并保存快照；后续聊天修改不会进入公开内容，点击“更新并复制链接”才更新快照，保留原地址。撤销链接后公开接口返回 404；公开响应不再返回账户和文件夹字段。
- **分享操作缺少失败反馈。** 创建、撤销和复制均捕获错误并防止重复提交；复制被拒绝时保留可手动复制的 URL，修复剪贴板降级失败却报告成功的问题。
- **语音录制入口与生命周期异常。** 恢复录音按钮；处理权限拒绝、浏览器不支持与转写失败；取消、退出或权限请求延迟完成时释放麦克风、计时器与音频上下文。浏览器语音取消不再触发确认，后端转写上传采用实际录制 MIME 与扩展名，追加到已有草稿时补齐必要空格。
- **聊天导入失败无法重试。** 在发送第一个聊天前检查整个文件结构；设置页与侧栏支持正常导出格式，保留元数据；提示解析与服务端错误、部分成功数量，刷新已导入内容并允许再次选择同一文件。后端同样拒绝无效聊天结构，侧栏多文件按顺序导入。
- **音频设置网络错误无反馈。** 保存失败保留字段并显示错误，提交期间防止重复保存；音频 API 统一处理网络错误与非 JSON 错误响应。
